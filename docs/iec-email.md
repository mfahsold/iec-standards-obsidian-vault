# IEC enquiry — ready-to-send email draft

This is a copy-paste covering note. The full list of questions is in
[`iec-engagement.md`](iec-engagement.md); refer to it rather than duplicating
every question here.

**To:** IEC Webstore contact — <https://webstore.iec.ch/en/contact/>

**Subject:** Request for guidance — public metadata catalogue and local RAG use (unofficial, non-commercial)

**Body:**

Hello IEC Webstore team,

We maintain an independent, non-commercial, open-source knowledge base that
catalogues a small, verified subset of public IEC bibliographic metadata
(references, titles, editions, committees, ICS codes, dates, price snapshots,
source links) and provides original summaries. It contains no IEC document
bodies, PDFs, or reproduced standard text. We paraphrase public pages and link
to the official sources; we do not scrape, and we do not use purchased IEC
publications in any model or index.

The metadata is also used in a local, offline retrieval tool that answers
questions with citations to the catalogue. The project is not affiliated with
IEC, uses no IEC logos, and states prominently that it is not official IEC
communication or documentation and may contain errors. The repository is public
at <https://github.com/mfahsold/unofficial-iec-metadata-vault>.

Could you please confirm whether this use is acceptable, what attribution you
prefer, whether price snapshots are acceptable, and whether a licence or
permission is required even for a small, attributed subset? The detailed
questions are listed in the repository document `docs/iec-engagement.md`; we are
happy to send them in a separate message if useful.

If IEC requests changes, we will apply them to the catalogue and documentation.

Thank you for your guidance.

[Name / contact]
