# Rights-Holder and Takedown Requests

This repository is an independent, unofficial aggregate of publicly available
IEC/ISO metadata. It is not official IEC or ISO material and may contain errors.
If you are a rights holder and believe any content here is inappropriate,
infringing, or exceeds acceptable use, we want to hear from you.

## How to report

Open a GitHub issue in this repository with:

- the exact file and passage or data field concerned;
- the reason for the request (copyright, trademark, accuracy, or other);
- any supporting source or documentation;
- what you would like us to do (remove, amend, attribute differently).

If the issue contains sensitive material, ask the maintainers to move the
discussion to a private channel instead.

## What we do

1. Acknowledge the request promptly.
2. Review the affected content against the project's data policy.
3. Remove, amend, or add attribution as appropriate — normally within a few
   working days.
4. Reply in the issue with the outcome.

We do not require formal legal process to act on a credible rights-holder
request. We may also remove content proactively if we believe it conflicts with
the project's public-safety rules.
