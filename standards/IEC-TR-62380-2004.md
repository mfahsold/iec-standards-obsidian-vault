# IEC TR 62380

**Data as of:** 2026-11-19 — mirror source (regional mirror, normservis.cz). No document bodies (copyright IEC — see `docs/provenance.md`).

## Description

IEC TR 62380 is a reliability data handbook with a universal model for
predicting the reliability of electronic components, PCBs, and equipment. It was
prepared by IEC Technical Committee 47 (Semiconductor devices).
