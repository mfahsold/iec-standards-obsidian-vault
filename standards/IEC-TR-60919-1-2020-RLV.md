# IEC TR 60919-1:2020 (RLV — Redline Version)

**Data as of:** 2026-11-19 — product page (Webstore). No document bodies (copyright IEC — see `docs/provenance.md`).

## Description

IEC Technical Report 60919-1, IEC TR 60919-1:2020(E) — contains both the official IEC International Standard and its Redline version. The Redline version is available in English only and provides you with a quick and easy way to compare all the changes between the official IEC Standard and its previous edition.

“Performance of high-voltage direct current (HVDC) systems with line-commutated converters - Part 1: Steady-state conditions.”

Gives general guidance on the steady-state performance of two-terminal HVDC systems using line-commutated (thyristor valve) converters — 12-pulse converter units of three-phase bridges; power flow in both directions; multi-terminal HVDC transmission systems are not covered; diode valves are not considered.
