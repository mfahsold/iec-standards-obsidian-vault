# ISO 14678:2005

**Data as of:** 2026-11-20 — third-party catalog (standards.iteh.ai). The scope
is adhesives, not the Internet. No document bodies (copyright ISO — see
`docs/provenance.md`).

## Description

ISO 14678:2005 specifies seven methods for assessing the flow characteristics
of adhesives after application at room temperature and during cure, measured by
sagging. Edition 1 (2005-08-15).
