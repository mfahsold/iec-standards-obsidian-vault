## Description

IEC Technical Report 62476, IEC/TR 62476:2010(E).

“Guidance for evaluation of product with respect to substance-use restrictions in electrical and electronic products.”

Provides a framework to evaluate electrical and electronic products with respect to restricted substances using internationally accepted standards, tools and practices. It can also apply to declarable (non-restricted) substances and includes guidance on how to select and apply technical documentation and relevant evaluation/control methods for any producer's product.
