## Statuses (Library Server view)

- “Latest publications” — active standards
- “Corrigenda / IS” — corrections/amendments
- “Replaced / Withdrawn” — superseded
- Vault frontmatter: `status: "active"` for all vault products (refreshed on update; removed → replaced/withdrawn)

## Development Process (IEC “logic” — the project stages)

PWI → NP → WD → CD → CDV → FDIS → APUB/PPUB (see [processes/development-stages.md](processes/development-stages.md)); target dates (6/12/24/33/36 months), SMB cancels projects >5y without approval ([processes/work-programme.md](processes/work-programme.md)).

## IEC “Philosophy” (views)

- Publication types: IS/TS/TR/PAS/ISH/IEV (+TRF).
- Consensus: 2/3 majority of P-members + <25% negative ([processes/international-standards.md](processes/international-standards.md)).
- Optional adoption (IEC FAQ).
- CBI recognition (WTO).
- Prices are dynamic (Webstore lists).
- “Publicly available” (Electropedia/IEV, Webstore catalogs) — Electropedia is free; IEC documents are paid (see [meta/licensing.md](meta/licensing.md)).
